Yunxin 是由中国台湾团队独立研发与运营的统一 AI API 平台，研发与日常运营并非由中国大陆团队负责。与常见仅套用通用面板、简单转发请求的中转服务不同，Yunxin 从账户与鉴权、API 密钥、统一计费、动态模型目录、协议转换、智能路由、故障回退、用量分析到管理后台均为自主建设，能够持续针对不同模型与供应商进行原生适配。 平台坚持“来源透明、隐私优先、调用可追踪”。每个模型可公开展示开发者、实际供应商、路由来源、模型能力、上下文长度、输出限制、价格、最低账户等级以及停用、弃用状态，并支持通过 `provider/model` 明确指定供应来源，尽量避免用户在不知情的情况下被模糊路由。模型目录会从上游动态同步并经过审核后上线，目前覆盖 OpenAI、Anthropic Claude、Google Gemini、DeepSeek、xAI、Mistral、Qwen、Kimi 等 24+ 家供应商和近百款模型。 Yunxin 原生兼容 OpenAI Chat Completions、OpenAI Responses API 与 Anthropic Messages API。开发者通常只需修改 Base URL 与 API Key，即可继续使用现有 OpenAI 或 Anthropic SDK；即使上游并不原生支持相同协议，平台也可进行透明的格式转换。除了聊天与文本生成，平台 API 还覆盖推理模型、视觉理解、函数调用、结构化输出、嵌入、图像生成、语音合成与识别、视频、音乐、3D、文件、批处理、集合与实时音视频等能力。 为提升稳定性，平台支持跨模型或跨供应商的自动路由与故障回退，并通过响应头公开回退原因、实际供应商、路由模式与请求编号，方便开发者审计及排错。每个 API Key 可独立设置速率限制，避免单一应用耗尽全部额度。模型能力与实时价格通过 Models API 动态提供，用户可以按照能力、价格和供应来源选择模型，而不必依赖容易过期的静态清单。 在用量与成本方面，Yunxin 采用统一 Credits 余额与按量计费，无需分别维护多家供应商账户。控制台及分析 API 可查看每次调用的 Token、费用、延迟、首 Token 时间、实际路由和回退情况；同时兼容多种常用用量监控工具的数据格式，方便现有仪表盘直接接入。批处理任务可获得约 50% 的价格优惠，提示缓存、最大输出限制和分 API Key 统计也帮助用户更准确地控制成本。 隐私方面，Yunxin 的公开政策明确说明：不会使用用户的 Prompt、Completion 或上传文件内容训练 AI 模型，不出售个人资料，也不会向其他用户共享 API 使用数据；API Key 采用哈希存储，数据在传输与静态存储时加密，上传文件使用带访问控制的私有对象存储。我们希望提供的不只是“能够调用模型”的中转接口，而是一套由中国台湾团队长期自主维护、来源清楚、价格可查、隐私边界明确、协议兼容完整并且可以持续观测的 AI 基础设施。

Qwen 中转站适合直接用于生产环境吗？
